# BA Agent: Natural-Language Data Analysis for Business Users

A browser-based analysis agent. Upload a CSV, ask business questions in plain English, and get answers, charts and insights. All numbers are calculated by code, never generated by a language model.

**Live demo:** https://YOUR-USERNAME.github.io/ba-agent/  (replace after enabling GitHub Pages)

## Problem

Business users often cannot write SQL or Excel formulas, so simple questions ("top products?", "why did sales drop?") wait on an analyst. Analysts lose time on repetitive data pulls.

## Solution

An agent that turns a plain-English question into tool calls on the uploaded data, then explains the result.

```
User question -> Agent plans -> Tool call (aggregate / monthly / anomaly / chart)
              -> Result checked -> Answer + chart (+ visible agent steps)
```

## Features

- CSV upload with automatic column type detection (number, date, category)
- Totals, top/bottom N, breakdowns, monthly trend, anomaly detection, summary insights
- Bar and line charts
- "Agent steps" panel showing the plan and each tool call
- Two modes: **Rules** (keyword intent detection, fully offline) and **AI agent** (an LLM chooses tools; available when the page runs inside Claude)

## Guardrails

- Asks about a column that does not exist (e.g. profit margin)? The agent says so and lists real columns. It does not guess.
- Vague question ("Sales?") -> asks a clarifying question
- Empty file or non-CSV upload -> clear error message
- Cell contents are treated as data, never as instructions (prompt-injection safe by design)

## User stories

- As a business manager, I want to ask questions in plain English so I do not need SQL or Excel.
- As an analyst, I want unusual days flagged automatically so I can investigate quickly.
- As an executive, I want a short insight summary so I can decide faster.
- As an analyst, I want the agent to refuse rather than invent numbers when data is missing.

## Limitations

- Rules mode understands a fixed set of question types
- Runs in the browser; very large files (100k+ rows) may be slow
- AI mode needs the page to be opened inside Claude; on GitHub Pages only Rules mode runs
